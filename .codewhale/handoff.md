## Почему (корень проблемы)

- Данные и сервер используют **кириллические** коды: `core.py` → `TYPES=("О","Д","Б","У")`;
  в `data/vacation.db` лежит UTF-8 `D0 9E` / `D0 91`.
- CSS в клиенте объявляет селекторы **латиницей**: `.O` `U+004F`, `.D` `U+0044`,
  `.B` `U+0042`, `.U` `U+0055`.
- Клиент клал в класс сырой код → `class="day О"` (U+041E) не совпадал с `.O` (U+004F)
  → правило не срабатывало, цвет не появлялся.
- В статической версии (`C:\inetpub\wwwroot\index.html`) это работало за счёт
  `CODE_MAP_RU = {"О":"O","Д":"D","Б":"B","У":"U"}`. При переносе на сервер карту не завели.

## Реверт

2. вернуть `(CM[t]||'')` → `(t||'')`
