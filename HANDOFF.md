# HANDOFF — раскраска дней в «Календаре»

Полное описание состояния и решений: **`.codewhale/handoff.md`** (это единственная
версия, которую читает рантайм на следующей сессии; не дублирую её здесь, чтобы
две копии не разошлись).

Коротко для человека:

- **Что изменено:** только `static\index.html`. Добавлена карта
  `const CM={'О':'O','Д':'D','Б':'B','У':'U'};` и в `renderCal` подстановка `(CM[t]||'')`
  вместо `(t||'')`. Причина: данные и `core.py` используют кириллические коды
  (`TYPES=("О","Д","Б","У")`), а CSS объявляет селекторы латиницей `.O .D .B .U` —
  класс не совпадал с правилом, цвет пропадал.
- **Git в проекте нет** — версионирования нет, изменение живёт только в рабочем файле.
- **Откат:** убрать строку `const CM=…;`, вернуть `(CM[t]||'')` → `(t||'')`, пересобрать
  образ. Копия «до»: `data\backups\index.html.20261002-120234.bak` (реконструкция).
- **Пересборка обязательна:** `Dockerfile` делает `COPY . .`, монтируется только `./data`,
  поэтому `.\stop.ps1 ; .\deploy.ps1` (или `docker compose up -d --build`).
- **Визуально подтверждено (2026-10-03):** цвета проверены в реальном браузере (headless
  Edge + Puppeteer) с авторизацией: Пархимович (Админ_общий) 05–08.01 зелёные, Морозов
  (ГП56) 18–30.01 зелёные. Скриншоты: `data\pankhimovich.png`, `data\morozov.png`.
  Данные в БД изменились с момента первого хендоффа (сейчас rev 15, 2 периода) — см.
  `.codewhale\handoff.md`.
- **Не проверено:** коды `Д`, `Б`, `У` — в живых данных их нет.
- **Важно при доработке:** новый код дня заводить и в `TYPES` (`core.py`), и в `CM`
  (`static/index.html`).
